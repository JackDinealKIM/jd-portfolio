# jd-portfolio

소상공인·자영업자를 위한 **원페이지 홈페이지 / 예약·문의 연결 / 업무 자동화** 제작 포트폴리오입니다.
각 항목은 실제로 열리는 웹 페이지이며, 브라우저에서 바로 동작을 확인할 수 있습니다.

- 라이브: https://jackdinealkim.github.io/jd-portfolio/
- 샘플: https://jackdinealkim.github.io/jd-portfolio/01-store-landing/
- 문의: mashiaro@naver.com

## 특징

- **에디토리얼 레이아웃**: 12칼럼 비대칭 그리드, 1px 헤어라인, 한글 세리프 디스플레이와 산세리프 본문의 조합
- **WebGL 히어로**: Three.js 셰이더 평면에 업종별 실사 사진을 입혀 미세한 웨이브와 마우스 패럴랙스를 줍니다. WebGL을 쓸 수 없으면 같은 사진이 그대로 보입니다
- **업종 전환**: `data-ind` 속성과 CSS 변수로 상호·문구·메뉴·후기·사진·강조색이 한 번에 바뀌고, 주소(`?ind=`)에도 남습니다
- **폰트 자체 호스팅**: 외부 CDN 없이 동작하도록 한글 폰트를 서브셋해 저장소에 포함했습니다
- **모바일**: 390px 폭까지 가로 스크롤 없이 확인, 키보드 탭 이동과 `prefers-reduced-motion` 지원
- **문의 버튼**: 샘플에서는 안내 문구가 펼쳐지고, 실제 납품 시 매장 채널로 연결합니다

## 항목 추가 방법

1. `02-.../index.html` 처럼 새 폴더를 만들고 페이지를 넣습니다.
2. 루트 `index.html`의 작업 섹션에 링크와 썸네일을 추가합니다.
3. 이 README의 표에 한 줄 추가합니다.
