# jd-portfolio

소상공인·자영업자를 위한 **원페이지 홈페이지 / 예약·문의 연결 / 업무 자동화** 제작 포트폴리오입니다.
각 항목은 실제로 열리는 웹 페이지이며, 브라우저에서 바로 동작을 확인할 수 있습니다.

- 라이브: https://jackdinealkim.github.io/jd-portfolio/
- 문의: mashiaro@naver.com

## 작업물

| # | 항목 | 설명 | 링크 |
|---|------|------|------|
| 01 | 업종별 원페이지 홈페이지 (3종) | 카페·식당 / 인테리어·설비 / 학원·공방 샘플. 상단 탭으로 상호·카피·메뉴·후기·지도·컬러가 전환됩니다. | [`01-store-landing/`](01-store-landing/) |

## 가격

| 상품 | 범위 | 기간 |
|------|------|------|
| 9.9만 원 | 원페이지 랜딩 (템플릿 기반 + 수정 1회) | 1~2일 |
| 14.9만 원 | 블로그·SNS 글감 생성기 / 엑셀 정리 툴 (단일 기능) | 2~3일 |
| 24.9만 원 | 업종 맞춤 홈페이지 + 예약·지도·문의 연결 패키지 | 3~5일 |

## 구성

```
jd-portfolio/
├── index.html                 # 포트폴리오 인덱스 (작업물 카드 · 가격 · 진행 방식)
├── 01-store-landing/
│   ├── index.html             # 3업종 전환 원페이지 샘플 (단일 파일, 외부 CDN 없음)
│   └── cover.jpg              # 카드 썸네일
└── README.md
```

## 특징

- **단일 HTML 파일**: 외부 CDN·이미지 호스팅 의존 없이 파일 하나로 동작 (폰트까지 내장)
- **업종 전환**: `data-ind` 속성과 CSS 변수로 상호·문구·메뉴·후기·지도·강조색이 한 번에 바뀜
- **모바일 대응**: 390px 폭까지 레이아웃 확인, 가로 스크롤 없음
- **문의 버튼**: 카카오톡·전화·예약 버튼은 샘플 안내 모달로 연결 (실제 납품 시 매장 채널로 연결)

## 항목 추가 방법

1. `02-.../index.html` 처럼 새 폴더를 만들고 페이지를 넣습니다.
2. 루트 `index.html`의 작업물 카드에 링크와 썸네일을 추가합니다.
3. 이 README의 표에 한 줄 추가합니다.
