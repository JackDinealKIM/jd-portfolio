# 06 · 마진·정산 계산기 — 팔기 전에 한 개당 남는 돈

스마트스토어·배달앱·공방 세 채널의 수수료·부가세·배송비·원가를 넣으면, 한 개를 팔 때 실제로 손에 쥐는 돈과 실질 마진율, 목표 마진을 위한 권장 판매가, 손익분기 가격이 바로 나오는 계산기입니다.

## 계산 방식

판매가를 `P`, 수수료율 합계를 `c`, 부가세율을 `v`, 개당 고정비(원가·포장·배송·고정비 배분)를 `F`라고 두면

```
부가세   = P × 10/110            (과세. 면세·간이는 0)
수수료   = P × c                 (플랫폼·중개 + 결제·카드)
개당 고정비 = 매입가 + 포장 + 배송비 + (월 고정비 ÷ 월 판매량)
순이익   = P − 부가세 − 수수료 − F
마진율   = 순이익 ÷ P × 100
```

- **목표 마진 권장가**: `P* = F ÷ (1 − c − v − m)`, 100원 단위 올림. 분모가 0 이하이면 "불가"로 표시합니다.
- **손익분기 가격**: `F ÷ (1 − c − v)`.
- **마진 경고**: 0% 미만 적자, 10% 미만 박리다매(빨강), 20% 미만 빠듯함(주황), 목표 달성(초록). 경고에는 항상 손익분기 가격과 목표 마진 기준 가격을 함께 적습니다.
- **월 정산**: 개당 순이익(원 단위 반올림) × 월 판매량.

## 동작

- **채널 3종** — 누르면 요율·예시 값·필드 라벨(배송비/배달비, 사입가/재료비)이 함께 바뀝니다. `?ch=` 딥링크 지원.
- **실시간 계산** — 입력할 때마다 결과·막대·표·월 정산이 다시 계산됩니다. 금액은 입력과 동시에 천 단위 쉼표가 붙고 커서 위치를 유지합니다.
- **목표 마진 역산** — 목표 마진율을 바꾸면 권장가가 바뀌고, "이 가격 적용" 버튼으로 판매가에 바로 넣을 수 있습니다.
- **요약 복사** — 채널·판매가·공제 내역·순이익·마진·권장가·손익분기·월 순이익을 평문으로 복사합니다.
- **A4 인쇄** — `window.print()`. 인쇄 시 입력 패널·히어로·비교 섹션은 숨고 정산서만 A4 한 장에 담깁니다(1페이지 확인).
- **초기화 / 예시 값** — 초기화는 판매가·원가·수량만 지우고 요율·목표 마진은 남깁니다.
- **저장 없음** — 입력값은 전송·저장하지 않습니다. 새로고침하면 사라집니다.
