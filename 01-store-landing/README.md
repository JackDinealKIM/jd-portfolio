# 01 · 업종별 원페이지 홈페이지 샘플

업종마다 **레이아웃과 디자인 시스템을 따로 만든** 원페이지 샘플입니다. 같은 템플릿의 색만 바꾼 페이지가 아니라, 구조·타이포·배경·섹션 구성이 서로 다른 세 개의 사이트입니다. 상단 인덱스에서 업종을 바꾸면 페이지 전체가 다시 그려집니다.

| 업종 | 상호 | 디자인 시스템 | 링크 |
|------|------|----------------|------|
| 카페·식당 | 온기커피 (구리 인창동 로스터리) | 미색 종이 에디토리얼 매거진 · 명조 중심 · 12칼럼 비대칭 그리드 | [`?ind=cafe`](?ind=cafe) |
| 인테리어·설비 | 바른욕실·설비 (구리·남양주) | 짙은 차콜 시네마틱 스튜디오 · Pretendard 볼드 · 풀블리드 히어로와 3일 공정 타임라인 | [`?ind=interior`](?ind=interior) |
| 학원·공방 | 흙과손 도예공방 (구리 인창동) | 흰 갤러리 룩북 · 명조와 넓은 자간 · 중앙 정렬 히어로와 교차 2단 스토리, 주간 시간표 | [`?ind=clay`](?ind=clay) |

## 파일

```
01-store-landing/
├── index.html                 # 세 업종 마크업·CSS·셰이더 (한 파일, 업종별 렌더러 분리)
└── assets/
    ├── cafe-hero.webp ...     # 업종별 실사 이미지 18장 (webp, 1024~1536px)
    ├── fonts/                 # Editorial Serif / UI Sans(400·500·600·700) / Index Mono 서브셋
    └── vendor/three.min.js    # r158 (MIT)
```

## 구조

- `index.html` 안에서 업종별 렌더 함수(`cafeHTML`·`interiorHTML`·`clayHTML`)가 각자의 섹션 구조를 만들고, CSS는 `.site--cafe` / `.site--interior` / `.site--clay`로 완전히 분리되어 있습니다.
- 히어로 사진은 Three.js 셰이더 평면으로 그립니다. 업종마다 파형·그레인·비네트·줌 값이 달라 같은 셰이더로 다른 질감이 납니다. WebGL이 없거나 로드에 실패하면 배경 사진이 그대로 보입니다.
- 폰트는 서브셋(`assets/fonts/*.woff2`)만 사용합니다. 문구를 고칠 때는 서브셋에 없는 글자가 생기지 않는지 확인하고, 필요하면 `fontTools.subset`으로 다시 만들어 주세요.

## 보는 법

- 로컬: `python3 -m http.server` 로 저장소 루트를 열고 `/01-store-landing/` 로 접속합니다. (WebGL 텍스처는 http에서만 로드됩니다)
- 업종 전환은 주소의 `?ind=` 값을 읽어 복원됩니다.
- 사진과 상호·후기는 모두 예시입니다.
