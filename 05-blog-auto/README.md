# 05 · 블로그 초안 생성기 — 제목·목차·촬영 가이드 5분

사장님이 블로그 한 편을 쓸 때마다 2시간 넘게 걸리던 일을 5분으로 줄이는 도구입니다.
업종을 고르고 키워드 한 줄을 넣으면, 네이버·구글 검색에 맞춘 제목 3안과 AI가 인용하기 좋은 3줄 요약, 소제목 목차, 사진 촬영 가이드, 발행 전 체크리스트가 바로 나옵니다.

## 동작

- **업종 4종** — 식당·카페 / 인테리어 / 시공·설비 / 공방·클래스. 업종마다 제목 템플릿, 3줄 요약, 목차(H2·H3), 촬영 가이드 5컷, 체크리스트가 따로 있습니다.
- **입력** — 핵심 키워드(필수), 상호(선택). 키워드는 지역+업종 형태가 가장 잘 맞습니다.
- **제목 3안** — 검색형(키워드 앞배치) · 경험형(후기 톤) · 정보형(체크리스트). 각 제목의 글자 수를 세어 40자를 넘으면 표시합니다.
- **AEO 3줄 요약** — “무엇을 · 누가 · 어떻게 확인하는가” 순서. AI 검색과 네이버 AI 브리핑이 첫 문단에서 답을 찾는 구조를 따랐습니다.
- **빈칸** — `[대표 메뉴]`, `[가격]`, `[공사 기간]` 같은 대괄호는 사장님만 아는 사실 자리입니다. 도구가 가격·후기를 지어내지 않게 비워 두었습니다.
- **복사** — 블록별 복사와 전체 복사를 지원합니다. 복사본에는 대괄호가 그대로 남아 바로 붙여 넣고 채울 수 있습니다.
- **저장 없음** — 입력값은 서버로 가지 않고 `localStorage`에도 남기지 않습니다. 새로고침하면 사라집니다.
- **딥링크** — `?ind=`로 업종을, `?kw=`로 키워드를 미리 채워 열 수 있습니다.

## 검증

- 1440×900 데스크톱, 390×844 모바일에서 가로 스크롤 없음 (`scrollWidth == clientWidth`)
- 콘솔 에러·페이지 에러 0건, 404 0건
- 깨진 이미지 0개 (사진·QR 포함)
- 업종 4종 × 키워드 입력 후 제목 3 · 요약 3 · 목차 8 · 촬영 5 · 체크 6개 생성 확인
- 업종 전환·키워드 입력·상호 입력·복사(블록/전체) 동작 확인
- 제목·요약의 조사 처리(은/는) 확인: 온기커피는 / 바른욕실은 / 정직설비는 / 흙공방은

## 참고

- 상호·가격·기간은 모두 예시입니다. 실제 발행 전에 매장 정보로 바꿔야 합니다.
- 사진은 생성 이미지이며, 실제 매장 사진으로 교체하는 것을 전제로 만들었습니다.
